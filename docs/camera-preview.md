# インカメ・外カメ

「自分」の動画選択でインカメ／外カメを選ぶ。起動後は映像の操作欄の「切替」で前後を切り替える。録画中・録画準備中は切り替え不可。プレビューは初期状態では反転しない。横16:9が標準で、両カメラともお手本の音楽再生・速度変更・録画に対応する。

切り替え時はお手本を一時停止し、旧カメラのトラックを止めてから新しいカメラを要求する。外カメは environment を必須指定し、外カメがない端末でインカメを外カメとして表示しない。使用中のカメラから切り替えられなかった場合は、元のカメラの再起動を試みる。ファイル選択などで中断した後に遅れて取得したストリームは停止する。

検証: tests/built-camera.mjs はブラウザ上で前後2種類の合成映像を実際の MediaStream として供給し、初期選択、設定からの選択、往復切り替え、取得失敗、古い要求のキャンセル、重ねる表示、390×700／844×390のレイアウト、録画中の切替ロック、音楽再生・速度変更中の録画を確認する。保存動画をデコードし1280×720で映像があることも確認。実機iPhoneのカメラやSafariでの検証は別途必要。
